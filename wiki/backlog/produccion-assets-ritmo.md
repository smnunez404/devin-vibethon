> Fase inicial de recursos. Para continuar con la construcción del juego, seguir [[CONTINUAR]] y [[wiki/backlog/desarrollo-juego-con-camara]]. El límite de no implementar gameplay al final de esta nota fue específico de esta fase.

- [x] Acceder al reproductor y registrar duración y título.
- [x] Guardar muestreo distribuido de las tres familias visuales.
- [x] Densificar capturas: 147 capturas con tiempos nominales y seis hojas de contacto; limitaciones temporales explícitas.
- [x] Resolver acceso al video: navegador disponible; descarga completa restringida por YouTube. Se usó muestreo visual y no se presenta como extracción del archivo original.
- [x] Producir notas de manos/pies, parejas y variantes de color con transparencia (primera versión SVG/PNG).
- [x] Producir recursos para receptores apagados/activos, pista y bordes (instanciar cuatro pads en la futura implementación).
- [x] Producir paredes, impactos, anillos, partículas y estelas (primera versión SVG/PNG).
- [x] Producir figuras guía por acción y recursos de calibración futura: once siluetas, panel y marco de encuadre.
- [x] Producir fondos de feria, contornos/diamantes y engranajes; SVG/PNG y tres MP4 con movimiento real de profundidad.
- [x] Producir HUD, números, valoraciones, instrucciones, pausa, cuenta atrás y resultados como recursos gráficos.
- [x] Producir sonidos de feedback y pista rítmica provisional con procedencia y condiciones de uso claras: ocho WAV sintetizados, documentación en `assets/v001/README.md`.
- [x] Biblioteca local con categorías en español, búsqueda, previews, reproducción de loops/audio, tamaño/formato y descargas.
- [x] Verificar integridad, transparencia, legibilidad de muestras y comparación contra capturas; auditoría en `assets/v001/audit.json`.
- [x] Documentar manifiesto de recursos, pivotes, dimensiones, integración futura y límites de la primera versión.

La lista corresponde al **kit inicial de recursos**, no a una réplica terminada ni al videojuego. Para una reconstrucción temporal exacta se necesitaría el archivo de video accesible, y para una versión de producción se requiere otra revisión artística y musical. Ver [[wiki/arquitectura/inventario-y-uso-assets-v001]].

## Límite del encargo

No implementar gameplay, cámara, tracking corporal ni evaluación de movimientos. Scripts de producción de assets y página de biblioteca sí forman parte del encargo.
