# CLAUDE.md

**Primero leer [CONTINUAR.md](CONTINUAR.md)** para recuperar el contexto, el enlace del video, el estado real, el kit de assets y el plan para construir el juego con cámara. Después leer [AGENTS.md](AGENTS.md), fuente canónica de las reglas del proyecto.

Devin Vibethon es el nombre de trabajo de un juego de ritmo/cardio que debe reaccionar a movimientos de manos, pies y cuerpo mediante una cámara. El usuario cambia de agente para empezar el desarrollo. La primera versión de assets existe; el juego y el modelo integrado no existen todavía. Stack y modelo son decisiones abiertas, con una ruta de validación propuesta en el handoff. No interpretar el cierre de la fase de assets como finalización del videojuego.
